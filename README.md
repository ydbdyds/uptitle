# Uptitle

Mac 刘海实时字幕：会议、网课里的语音实时变成字幕，显示在 MacBook 的刘海下方，可以同时翻译。

安装包在 [Releases](https://github.com/ydbdyds/uptitle/releases) 里。需要 Apple 芯片的 Mac，macOS 26.4 或更新版本。

Live captions under the MacBook notch for meetings and lectures, translated as they are spoken. Download the app from [Releases](https://github.com/ydbdyds/uptitle/releases). It needs a Mac with Apple silicon and macOS 26.4 or later.
